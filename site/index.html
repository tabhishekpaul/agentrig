Your AI rig.
In one place.

The control panel for your AI coding setup. See every skill, plugin and MCP server across your tools, know what they cost you, install new ones safely, and keep every computer in sync.

$curl -fsSL https://tabhishekpaul.github.io/agentrig/install.sh | sh

Then open arig.localhost:7377. arig keeps running in the background and starts at login.

01

Everything, one list

Skills, plugins and MCP servers from every tool on your machine, sorted into categories and searchable. Flip any of them on or off without touching a config file.

02

Know what it costs

Every enabled skill rides along on every message. See the token cost per tool, which skills you actually use, and switch off the rest in one click.

03

Your AI picks the skill

Built-in MCP server: Cursor, Codex, Claude and friends search your skills and load the right one when a task needs it.

04

Install safely

Search and install from the skills.sh registry. Every skill is flagged if it runs scripts or uses the network, and shows you a diff before any update.

05

Per project, packs, profiles

Commit a project's skills in its .arig/ folder, group skills into packs, save setups as profiles, and write or publish your own.

06

Same setup everywhere

Sync through a private git repo you own. API keys and secrets never leave your computer, and nothing is tracked.
